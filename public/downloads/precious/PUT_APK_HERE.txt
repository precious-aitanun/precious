Put TWO files in this folder, named exactly:

    precious-v1.1.0.apk    ← latest (OSCE Clerking Stations + AI Study
                              Assistant + attached study material PDFs)
    precious-v1.0.0.apk    ← previous release (this is your existing
                              app-latest.apk — just rename it)

The site reads both automatically once they're here (see config/apps.ts
→ apps[0].versions). The download button always serves precious-v1.1.0.apk;
precious-v1.0.0.apk shows up under the "Previous versions" toggle on the
download section. File size shown on the site is read from the real file
at build time — nothing to type in manually.

To ship a future update:
1. Add the new APK file here with a new version number in the filename.
2. Add a new entry at the TOP of the `versions` array for this app in
   config/apps.ts (version, versionCode, releaseDate, releaseNotes,
   apkPath, apkFileName). The old entries stay — they become "Previous
   versions" automatically.
3. Commit and push — Vercel redeploys automatically.

Delete this .txt file once both real APKs are in place (harmless to
leave, but no reason to keep it).

Prefer hosting APKs elsewhere instead (e.g. Cloudflare R2, S3)? Set
`apkPath` for that version in config/apps.ts to the full https:// URL
instead of a local path — this folder isn't needed for that version.
