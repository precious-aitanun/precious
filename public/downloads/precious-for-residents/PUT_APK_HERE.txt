Put ONE file in this folder, named exactly:

    precious-for-residents-v1.0.0.apk

The site reads it automatically once it's here (see config/apps.ts →
apps[1].versions). File size shown on the site is read from the real
file at build time — nothing to type in manually.

To ship a future update, same pattern as the Precious app: add the new
APK here, add a new entry at the TOP of this app's `versions` array in
config/apps.ts, commit, push.

Delete this .txt file once the real APK is in place (harmless to leave,
but no reason to keep it).
